# 0.0.23

Released 2026-11-20, the jspassgen suite's second lockstep release. The
full list is in the
[changelog](https://github.com/sebastienrousseau/jspassgen-sdk-python/blob/main/CHANGELOG.md).

## Highlights

- **Fuzzed with Atheris**: the public API's contract (range, length,
  errors and their messages, the rejection loop) runs under libFuzzer
  from a seed corpus in `make fuzz` and a 60-second CI job, and the
  unit tests replay the same contract on every platform.
- **No download piped into an interpreter**: the release workflow reads
  PyPI's file digests with `jq` from a saved response.
- **CODEOWNERS**: every file is owned by the maintainer.

The library is unchanged from 0.0.22: the same `RandomGeneratorPort`
and `SecretsRandom`, with the same behaviour. It generates no passwords
yet; the generators are ported against the core's conformance kit in a
later version.
