# 0.0.24

Released 2026-11-21, the jspassgen suite's third lockstep release. The
full list is in the
[changelog](https://github.com/sebastienrousseau/jspassgen-sdk-python/blob/main/CHANGELOG.md).

## Highlights

- **SLSA build provenance on every release**: the release workflow
  attests each release file with `actions/attest-build-provenance`,
  signed through Sigstore, and attaches the bundle as
  `jspassgen-sdk-python-<version>.intoto.jsonl`, listed in the release
  checksums. Check a download with
  `gh attestation verify <file> --repo sebastienrousseau/jspassgen-sdk-python`.

The library is unchanged from 0.0.23: the same `RandomGeneratorPort`
and `SecretsRandom`, with the same behaviour. It generates no passwords
yet; the generators are ported against the core's conformance kit in a
later version.
