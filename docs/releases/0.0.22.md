# 0.0.22

Released 2026-11-18, the repository's first version and the jspassgen
suite's first lockstep release. The full list is in the
[changelog](https://github.com/sebastienrousseau/jspassgen-sdk-python/blob/main/CHANGELOG.md).

## Highlights

- **The random port, on `secrets`**: `RandomGeneratorPort` with
  `random_bytes(n)` and `random_int(max)`, and `SecretsRandom`, whose
  `random_int` is unbiased by rejection sampling.
- **Tested for bias**: range, uniformity (chi-squared), the absence of
  modulo bias, the rejection loop and every error, plus a test that the
  library imports nothing that reaches the network and not `random`.
- **Signed releases to PyPI**: `release.yml` refuses an unsigned or
  mismatched tag, runs `make check` and `make audit`, and publishes
  through trusted publishing with `SHA256SUMS`.

This version generates no passwords yet; the generators are ported
against the core's conformance kit in a later version.
